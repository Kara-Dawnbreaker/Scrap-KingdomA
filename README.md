# Scrap Kingdom: A Dead Country

A single-player scrapyard management and industrial business simulation set in a fictional country recovering from industrial collapse.

> **Repository preparation stage:** This commit organizes the project and records its design/architecture. No gameplay code, application code, or engine-specific implementation has been started.

## Project principles

- Resourcefulness and meaningful material use
- Discovery through controlled experimentation
- Business, workforce, production, and logistics management
- Visible physical development of the scrapyard
- Accessible complexity without excessive micromanagement
- Data-driven content and separation of simulation from rendering

## Repository map

- `docs/` — design, architecture, planning, decisions, and testing documentation
- `src/` — future application and game systems, separated by responsibility
- `data/` — future data-driven definitions for items, recipes, buildings, workers, vehicles, locations, customers, and economy
- `assets/` — future visual, audio, font, and UI resources
- `tests/` — future automated and manual test organization
- `tools/` — future development and content utilities

See [Project Structure](docs/architecture/PROJECT_STRUCTURE.md), [Architecture Plan](docs/architecture/ARCHITECTURE.md), and [Roadmap](docs/development/ROADMAP.md).
