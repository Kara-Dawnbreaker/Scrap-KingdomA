# Development roadmap

The order follows the GDD. Each phase should be validated before broadening scope.

1. **Foundation:** core rendering, camera, yard layout, input, navigation, save system.
2. **Core Business:** inventory, item definitions, buying, selling, storage, basic customers.
3. **Scavenging:** locations, vehicles, crews, expedition preparation/resolution, salvage recovery.
4. **Processing:** sorting, dismantling, repair, manufacturing, production queues.
5. **Discovery:** experimentation, recipe discovery, notebook, mastery, worker expertise.
6. **Workforce:** recruitment, skills, assignments, experience, payroll, automation.
7. **Economy:** dynamic markets, orders, contracts, negotiation, reputation, business tiers.
8. **Expansion:** buildings, vehicles, recipes, locations, customer types, advanced chains.
9. **Final Polish:** pixel art, animation, sound, balancing, save reliability, mobile optimization, performance testing.

## Delivery rule
Build vertical slices that prove the connected economic loop. Avoid implementing every menu or content category before the underlying systems work together.
