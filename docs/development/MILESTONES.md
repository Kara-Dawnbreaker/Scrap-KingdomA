# Initial milestones

Milestones are planning checkpoints, not calendar promises.

- **M0 — Repository preparation:** GDD, folder structure, project documentation.
- **M1 — Technical blueprint:** stack selection, architecture boundaries, prototype scope, and test strategy.
- **M2 — Application shell:** Vite + TypeScript setup, Phaser canvas, HTML/CSS interface, build and type-check scripts.
- **M3 — Yard proof:** top-down orthogonal grid, camera pan/zoom, selection, and modest-desktop performance check.
- **M4 — Simulation foundation:** authoritative game state, simulation clock, seeded randomness, command validation, and test harness.
- **M5 — First trade loop:** starter inventory, market prices, buy/sell commands, and cash ledger.
- **M6 — First expedition:** destination selection, crew/vehicle preparation, simulated outcome, report, and returned cargo.
- **M7 — First processing chain:** sorting or dismantling with validated inputs and outputs.
- **M8 — Persistence:** IndexedDB save/load, versioned schema, autosave checkpoints, and backup export/import.
- **M9 — Connected prototype:** complete acquire → store → process → sell → reinvest loop with acceptance tests.
- **M10 — System expansion:** deeper economy, workforce, customers, contracts, discovery, facilities, and regions.
- **M11 — Release preparation:** PWA/offline checks, mobile adaptation, audio, performance, accessibility, and save migration checks.

The prototype is considered successful only when the player can complete the connected loop, save, reload, and continue without unexplained loss or duplication of stock or money.
